# 1. PROJECT OVERVIEW

Build a complete, functional Python backend application for Society Desk.

Society Desk is an AI-powered apartment maintenance management system that enables residents to report maintenance complaints through Discord.

Three AI agents collaborate through Switch Console to manage the complete maintenance workflow.

The system consists of:

1. Helpdesk Agent – receives complaints and manages tickets.
2. Operations Agent – analyses maintenance history, detects recurring faults, recommends vendors and checks budgets.
3. Treasurer Agent – handles work-order execution after human approval.

The Python application is the central backend and source of truth for all maintenance data.

Switch Console manages agent orchestration, communication, permissions and human approval.

Claude agents understand requests, interpret backend results and coordinate the workflow.

Python enforces business rules, performs calculations, validates requests and stores records.

This is a GROUP HACKATHON PROJECT. The application must support collaboration between multiple team members.

- Decline.

- Validate the vendor.
- Validate the amount.
- Validate available budget.
- Create the work order.
- Update budget spending.
- Record the transaction in ticket history.

Perform all financial database changes inside a single transaction.

IMPORTANT:
- Do not build a fake approval mechanism.
- Do not automatically approve requests.
- Do not allow the Treasurer Agent to approve itself.
- Do not bypass Switch permission checks.
- The Switch approval must happen before Python executes the work-order command.
